DeepSeek Harness 2.0 & V4.1 Workspace
====================================

Description
-----------
Local agent integration suite and web harness engine powered by DeepSeek V4.1 Flash.

Usage
-----
1. Install dependencies:
   npm install

2. Run test suite:
   npm test

3. Launch agent service:
   npm start

System Service
--------------
Managed via systemd user unit: deepseek-harness.service
